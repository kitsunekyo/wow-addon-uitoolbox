# Enhanced Interface

Enhanced Interface is a retail World of Warcraft addon focused on small, practical UI improvements. The goal is to enhance the default WoW interface in a ways that feels unobtrusive and fits nicely into the default design philosophy.

Built for WoW Retail (Midnight)

## Dev Note

The project is built with the help of opencode agents. I try my best to be a good human in the loop, to ensure the resource usage of the addon is kept as low as possible. If you find anything not working correctly feel free to create an issue and I'll have a look.
